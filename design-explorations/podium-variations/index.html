Podium, five ways

Five variations on Direction 2. They all keep its core: the rank sets the layout, colour is flat, and Archivo's width axis does the shouting. Each pushes in a different direction, and several fix Podium's weak spots: long option text, dark mode, and too much yellow. The original is on the left for reference. Every phone is live, so you can drag, switch the counting method, and watch votes arrive.

Original

Yellow poster, black steps.

A · Floodlight

Dark twin. Yellow becomes the light on the leader.

B · Scoreline

Loud numerals, readable sentences. Survives long options.

C · Signal Sets

Every poll gets its own colour.

D · Medal Stand

A literal 2-1-3 podium that follows the votes.

E · Sticker Party

Outlined, crooked, slapped-down stickers.

How they compare

VariationFixes or addsProsCons
A · FloodlightDark mode for Podium.Keeps the automatic light/dark switching the app has today. Calmer on the eyes, and the leader stands out more. Strong on a projector.Not a standalone identity; it's the night version of another theme. Hard offset shadows don't work on black.
B · ScorelineLong option text, admin screens.Handles 200-character options and wrapping. Light ground scales to settings and admin. Still unmistakably Podium thanks to the numerals.The least loud. Loses some of the poster punch in exchange for being readable.
C · Signal SetsYellow fatigue; telling polls apart.Polls become recognisable (recent list, link previews, the projector). It's only one token per poll, so it's cheap to build. Pairs with any of the others.Brand colour is no longer fixed. Each new signal needs a contrast check. Some hosts will want to pick the colour themselves.
D · Medal StandA signature results moment.Makes the name literal and memorable. Your podium previews live while you drag. Shows the top 3 at a glance.Spends a lot of screen on three options. Ties and polls with only two options need special cases.
E · Sticker PartyDelight and play.The most fun to drag. Very shareable. Great for kids, classrooms and parties.Too loud as the default for every poll. Tilted rows are slightly harder to scan. The most CSS to maintain.

My pick: Scoreline as the base, Signal Sets for colour, Floodlight for dark.

These three fit together into one system. B fixes Podium's real problem (long options) and works on admin screens. C takes the yellow fatigue away and makes each poll recognisable. A is the same system with the lights off, so the app keeps following the system theme.

  2. Offer E as an optional "party" theme the host can turn on per poll.
