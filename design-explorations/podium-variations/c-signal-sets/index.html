Signal sets

Podium, but yellow is no longer the only colour. Each poll gets a signal colour of its own, picked from its code (or by the host): tomato, cobalt, mint, yellow, pink, black. The layout grammar never changes, so it's still unmistakably Rankzap, but your polls become things you recognise at a glance, in the recent list, in link previews, on the projector.

What changes from Podium

The signal is a per-poll token (one CSS variable set). Black and white stay fixed; each signal has a tint for the bench rows. Every pairing is chosen so text stays at 4.5:1 or better.

Motion

  • Opening a poll from home: its tile expands to fill the screen and becomes the ballot background.
  • Same staircase springs; the browser's theme colour follows the poll so the whole phone turns that colour.
